# Sleeve-Entwürfe – Runde 4 (50 Stück)

50 neue Sleeves nach den gesammelten Nutzer-Regeln (`BRIEF.md`): nur vorhandene Grafik aus den xcf-Ebenen,
vollständige Figuren, einheitliche Pixelgröße je Tiefenebene, eigene Effekte in sauberer Pixel-Art, kein Text,
ausgewogene Komposition, keine Doppelungen mit den bestehenden Shop-Sleeves. Gebaut in zehn Blöcken (A–J, je fünf
Sleeves, Notizen `notes_A.md` … `notes_J.md`, Ideenliste `concepts.md`); jedes Sleeve wurde nach einem Review
mindestens einmal überarbeitet.

- Rohbilder ohne Rahmen: `NN_name.png`, Übersicht `00_overview.png`
- Gerahmt: `final/<Name>.png`, Übersicht `00_overview_final.png`
- Skripte: `generator/sNN_*.py` (aus `generator/` ausführen, `from common import *`), Sprite-Cache `generator/sprites4/`
- Rahmen + Shop: `generator/frame_r4.py` (Tabelle `generator/frames_r4.json`: Datei → Name, Bauform, Palette,
  Steine) rahmt mit `runde3/generator/frames2.py`, kopiert nach `data/shop/sleeves/<id>.png` und trägt die
  Anzeigenamen in `data/shop/sleeve-names.json` ein.
