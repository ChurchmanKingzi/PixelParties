Trained CPUs vs. untrained CPUs

Single test games: ONE trained seat (learned profile + best play style) against untrained default bots at tables of 2, 3, 4 and 6 players. Without an edge the win rate equals 1 / players. Every checkpoint is a batch of such games; the line shows how the win rate develops with the number of training games.

Lookahead (search) vs. the same agent without lookahead

One seat additionally searches (tries its best candidate actions in a simulation of the game before choosing), all other seats play the same learned style without search. Without an edge the win rate equals 1 / players.

All cards by learned value

Value = mean placement score (+1 win … −1 last) of all games in which the card was dealt to a bot (starting hand or recycler), shrunk toward 0 for few observations. “Built” = the same for bases the card actually stood in, “Play” = average swing of the position evaluation when the card is played/activated, Δ = change since the last checkpoint. Updates continuously while training runs.

Keep or recycle — learned with the rest of the hand as context

Edge = expected difference in placement score (+1 win … −1 last) between keeping a card and recycling it, given the rest of the hand and the board. Cards cannot be judged in a vacuum, so pairs and requirements are learned separately.
